# Paraşüt API V4

> Paraşüt is a Turkish cloud pre-accounting (ön muhasebe) and e-invoicing SaaS. Its API V4 lets applications read and write nearly everything the Paraşüt web UI can do: contacts, products, inventory/warehouses, sales invoices and offers, purchase bills, bank/cash accounts and transactions, employees and salaries, taxes, and the official Turkish e-document flows (e-Fatura / e-Arşiv / e-SMM). The API follows JSON:API conventions and is authenticated with OAuth2.

## Key facts

- Base URL: https://api.parasut.com/v4/{company_id}
- Standard: JSON:API (jsonapi.org); media type application/vnd.api+json
- Auth: OAuth2 (authorization_code and password grants); Bearer access_token valid 2 hours; rotating refresh_token. Client credentials are requested from destek@parasut.com.
- Rate limit: 10 requests per 10 seconds
- Pagination: page[number] / page[size]; filtering via filter[...]; sorting via sort; compound documents via include
- Async: e-document creation is asynchronous via TrackableJobs (poll showTrackableJob; job id valid 15 minutes; generated PDF URLs valid 1 hour)
- Errors: JSON:API errors[] envelope with title/detail
